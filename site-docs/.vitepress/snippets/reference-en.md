> **Reference scope:** checked against the Sessions Viewer 0.6.0 adapters on 2026-10-05, not a compatibility guarantee for every CLI release. Shell examples use macOS/Linux paths and require `jq` (or `sqlite3` for opencode). Replace placeholders with real values and use your configured data root. Text extraction does not replay tools, images or the active branch of a session tree. Command regressions use [downloadable synthetic samples](/guide/compatibility#synthetic-samples), not private sessions. Check the [capability and evidence matrix](/guide/compatibility#support-matrix) for tested scope. Browsing is distinct from resuming or editing data; see [privacy and data handling](/guide/privacy).
