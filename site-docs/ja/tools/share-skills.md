# 複数のコピーではなく 1 つのスキルを共有する

Claude Code、Codex などのフォルダに同じスキルがある場合や、移動後に見つからなくなった場合の手順です。ツール管理はファイルと参照を整理しますが、各 agent の動作を同等に変換するものではありません。

## 1. 変更前に調べる {#inspect}

サイドバーのレンチまたは macOS `⌘K` から Skills を開きます。重複、迂回、切れたリンクを選び、名前だけでなく **Content**、**References**、**Enabled in** を確認します。

![重複と切れたリンクを絞り込む一覧](/screenshots/tools-skills.png)

| 検出 | 先に確認すること |
| --- | --- |
| 重複 | 同じ内容か、プロジェクトで意図的に版を分けたか |
| 迂回 | 最終参照先が存在し、どの中間リンクを省くか |
| 切れたリンク | 本文が別の場所にあるか、本当に削除されたか |

リスク表示は確認すべきパターンで、安全認証ではありません。未知のスキルを使う前にスクリプトと依存を読みます。

## 2. 残す本文を選ぶ {#choose-source}

コピーを比較します。プロジェクト専用版は別に残す必要がある場合があります。**Move to main store** では移動元／先、移動とリンクの手順、競合を確認してから適用します。ファイルとリンクを変更するため、大切な独自内容は別にバックアップしてください。

![移動とリンク作成の適用前プレビュー](/screenshots/tools-skills-adopt.png)

使う agent だけを有効にします。同じファイルでも読み込み範囲や解釈が同じとは限りません。

## 3. 本文ではなく参照を修復する {#repair}

プレビューの最終パスを確認します。迂回修復は中間リンクを省いて本文に直接つなげます。本文がなくなった場合は参照を整理できても、削除済みの内容は復元できません。意図と違えばキャンセルします。

![本文のフォルダに直接つなぐ修復プレビュー](/screenshots/tools-skills-repair.png)

削除は統合とは違い、参照とコピーを削除する場合があります。範囲を確認してください。[管理の全体像](/ja/tools/#skills)に詳細があります。

## 4. 対象 agent で確認する {#verify}

対象の読み込み方法に従って再読込・再起動し、スキルを検出できるか確認します。見つからなければプロジェクト／全体の範囲、保存先、OS のリンク対応を確認します。読み込みは対象 agent の責任で、特定 CLI 版の認証ではありません。

新しいものは[スキル検索](/ja/tools/#discover)を使います。インストールは外部コマンドと通信、hooks は実際のスクリプト実行を伴い得ます。サンドボックスではありません。[データの扱い](/ja/guide/privacy)も確認してください。

根拠：2026-10-05 に 0.6.0 の[スキル書き込み](https://github.com/jerrywu001/cc-sessions-viewer/blob/22fefc6/src-tauri/src/tools/skills_write.rs)と[リンク処理](https://github.com/jerrywu001/cc-sessions-viewer/blob/22fefc6/src-tauri/src/tools/link.rs)を照合。[検証範囲](/ja/guide/compatibility)、[MCP 確認](/ja/tools/check-mcp)も参照できます。
