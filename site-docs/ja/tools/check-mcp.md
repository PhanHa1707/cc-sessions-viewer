# MCP の設定を変更する前に確認する

設定ファイルの MCP 項目は接続・認証・ツール利用の成功を意味しません。Sessions Viewer で読み込み元と変更を確認し、実行時の接続は対象 agent で検証します。

## 1. 設定元を確認する {#provenance}

ツール管理の MCP servers を開き、**Active in**、ファイル、コマンド／URL、所有 agent を調べます。Grok は Claude の設定を読む場合があり、共有項目の変更は両方に影響し得ます。

![設定元と文脈推定を示す MCP 一覧](/screenshots/tools-mcp.png)

直接の設定と互換読み込みを区別してから削除・コピーします。JSON と TOML は違うため、同じ断片を貼るのではなく対象形式のプレビューを確認します。

## 2. 文脈推定を理解する {#context-estimate}

Pi と Antigravity のローカルなツール定義キャッシュを読み、測定のためにサーバーを起動しません。**4 文字で約 1 トークン**で、選択したモデルの正確な tokenizer ではありません。キャッシュがない場合は未測定で、ゼロではありません。

ツール定義の目安であり、応答、将来の呼び出し、正確な課金量は含みません。同名のサーバーはキャッシュ検索を共有し得るので、実体を確認してください。

## 3. 1 つの変更をプレビューする {#preview}

対象 agent の有効化／無効化、編集、コピー、削除を選び、確定前に次を確認します。

- 対象ファイルと agent、互換読み込み先。
- 前後の値と無関係な項目の保持。
- コマンド、実行パス、環境参照と URL。
- バックアップと競合。確認後に変更されたファイルは再読込し、強制上書きしません。

一覧の秘密情報はマスクされても、表示を許可した詳細／プレビューには現れ得ます。スクリーンショットと共有ファイルを確認し、実際のキーを例に使わないでください。

## 4. 実際の動作は別に確認する {#runtime-check}

対象 agent を必要に応じて再読込し、起動、認証、ツールを確認します。保存成功はネットワーク、依存コマンド、プロトコル、権限の成功を保証しません。

問題があればアプリ／agent の版と匿名化した構造を記録し、実行ファイル、設定範囲、環境、サービスアクセスを確認します。秘密情報や設定全体を公開しないでください。設定の共有ファイルは選択した構成の共有用で、秘密情報込みの完全なバックアップの代わりではありません。

[MCP の管理](/ja/tools/#mcp)と[スキル共有・リンク修復](/ja/tools/share-skills)も参照してください。Hook の dry-run は実際のコマンドを実行するため、セキュリティ用サンドボックスではありません。
