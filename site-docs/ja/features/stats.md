# トークン使用量と推定コスト

Sessions Viewer が集計するのは**記録済みの使用量**で、プロバイダの請求書ではありません。`⌘⇧S` で統計を開き、プロジェクト、モデル、ツール、期間を比較できます。使用量がないことは無料の証明ではなく、対応する Antigravity CLI の形式にはトークンフィールドがありません。

![プロジェクト・モデル別の使用量とコスト](/screenshots/stats.png)

## 比較できる項目 {#usage-breakdown}

- プロジェクトとモデル：記録されたトークンと推定支出の内訳。
- ツール：呼び出しの種類と回数。
- 期間：今日、過去 7 日、過去 30 日。
- エージェント：全体または 1 つのソース。

対象は記録の内容とアダプターが認識する形式に依存します。異なるソースを比較する前に[対応範囲と検証表](/ja/guide/compatibility)を確認してください。

## 価格の出どころ {#price-source}

[models.dev 形式の js-bridge ミラー](https://www.js-bridge.com/api/models)から取得し、失敗時は [models.dev](https://models.dev/api.json) を使います。価格は 24 時間キャッシュします。価格一覧の通信であり、会話本文の送信は不要です。

![アプリ内のモデル価格表](/screenshots/model-price.png)

既知の料金は価格表で確認できます。一部の計算経路は未知のモデル ID に代替推定を使います。欠落したキャッシュ料金や不明なプロバイダ価格にも注意してください。欠落は使用量ゼロ・実際の料金ゼロの証明ではありません。

## 表示コストは請求額ですか {#cost-vs-bill}

いいえ。契約価格、ルーティング加算、割引、サブスクリプション、ツールなどの料金を含むとは限りません。キャッシュとモデルの対応づけも影響します。会計上の確認には実際の利用レポートと請求書を使ってください。

opencode は DB に記録されたコストを使い、サブエージェントも含めます。ただし独立検証済みの請求書ではありません。[opencode のコスト根拠](/ja/agents/opencode#cost-from-db)を参照してください。

対応する Antigravity CLI はトークン使用量に寄与しません。ほかのエージェントも使用量フィールドが必要です。本文だけの合成サンプルはコスト集計を検証するものではありません。

## 契約の利用枠との違い {#subscription-quota}

Claude と Codex の契約アカウントでは入力欄の横に利用枠を表示できる場合があります。認証とプロバイダが返す期間に依存し、API キーのアカウントには同じ契約利用枠の表示はありません。

残りの利用枠とトークン価格による支出は別です。更新時には認証済みのサービス／CLI への通信が起こり得ます。[プライバシー](/ja/guide/privacy)を参照してください。

## macOS メニューバー

エージェントごとの今日・7 日・30 日の合計を表示します。統計画面と同じ対象範囲・推定の制限が適用されます。
