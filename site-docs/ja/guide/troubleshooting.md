# セッションが見つからないのはなぜですか

まず**保存先・プロジェクト情報・記録形式**を確認します。CLI が走査範囲外に保存していたり、アーカイブや別のプロジェクトパスに分類されている場合があります。空の一覧だけで削除されたとは判断できません。

## 1. 想定した場所に記録がありますか

[保存先と形式の比較](/ja/agents/)から対応するリファレンスを開き、既知の 1 ファイルに読み取り専用のコマンドを使います。認証ファイルを探したり、個人のデータを公開 issue に貼ったりしないでください。

- ファイルがない：CLI がセッションを保存したか、同じ OS ユーザー／ホームを見ているか確認します。
- 別の場所にある：移動前に、実際の保存先とビューアが認識する設定を比較します。
- opencode DB がある：JSONL を探すのではなく `mode=ro` で照会します。

## 2. デスクトップアプリにも同じ設定が渡っていますか

[保存先の設定表](/ja/agents/)と、Grok、Kimi、Pi、opencode の `GROK_HOME`、`KIMI_CODE_HOME`、`PI_CODING_AGENT_DIR`、`PI_CODING_AGENT_SESSION_DIR`、`XDG_DATA_HOME` を比較します。Pi は `settings.json.sessionDir` も読みます。

ターミナルで export した値が、Finder やショートカットから起動したアプリへ渡るとは限りません。起動環境を合わせた後にアプリを再起動して確認してください。グローバル環境を無条件に変更する勧めではありません。

現在の Claude Code、Codex、Antigravity はホーム配下の固定場所を読み、CLI の別保存先を自動走査しません。元のデータをバックアップしてください。使用中のファイルを移すより、検出規則の改善が安全です。

## 3. アーカイブや別プロジェクトではありませんか

- **Codex アーカイブ：**`~/.codex/archived_sessions/` とアプリのアーカイブ表示を確認します。続行には Codex 側でアーカイブ解除が必要な場合があります。
- **プロジェクトの移動：**別パス、linked worktree、シンボリックリンク、古いチェックアウトは別プロジェクトとして扱われることがあります。[メタデータの比較](/ja/agents/)を使い、フォルダ名だけで判断しないでください。
- **見覚えのないタイトル：**特徴的なプロンプトをグローバル検索します。
- **ゴミ箱：**アプリで明示的に削除した場合は、再作成前に[共有ゴミ箱](/ja/features/export-and-trash)を確認します。

## 4. 読める形式・権限ですか

バックアップまたは書き込み停止中のファイルを読み取り専用で確認します。

- JSONL の各行は有効な JSON である必要があります。書き込み中は最終行が一時的に未完成の場合があります。
- Codex の先頭は `session_meta`、Pi は ID・時刻・`cwd` を含む `session` ヘッダーです。
- Grok は `chat_history.jsonl` ではなく `updates.jsonl`、Kimi の主記録は `agents/main/wire.jsonl` です。
- Antigravity は両方の transcript を圧縮する場合があります。大きいほうを確認しても、両方から失われた内容は復元できません。
- opencode の旧ファイル形式や変更後の SQLite スキーマは、新しいアダプターが必要な場合があります。

現在のユーザーがファイルと親ディレクトリを読めるか確認します。権限を回避したり、パーサに合わせて元の履歴を書き換えたりしないでください。

## 5. 不具合報告に何を含めますか

アプリ／CLI のバージョン、OS、想定する保存構成、カスタム保存先の有無、失敗する形を示す最小の合成サンプルを記載します。ユーザー名やパスは伏せ、実行中かアーカイブ済みかも示します。認証情報や個人の DB 全体は添付せず、[プライバシー](/ja/guide/privacy)を参照してください。

[issue を作成](https://github.com/jerrywu001/cc-sessions-viewer/issues)するか、[最新版をインストール](/ja/guide/install)してください。規則は 2026-10-05 に[ソース版 22fefc6](https://github.com/jerrywu001/cc-sessions-viewer/tree/22fefc6/src-tauri/src/agents)と照合したもので、すべての CLI 版での検証ではありません。
