# Sessions Viewer は完全にオフラインですか

**履歴の解析・検索・エクスポートはローカルで実行しますが、アプリ全体が通信しないわけではありません。** 続行時は設定した CLI／プロバイダを使い、更新確認、モデル価格、契約の利用枠も通信する場合があります。機密情報を扱うときは機能を区別してください。

## 読み取りと書き込みの違い

| 操作 | データの扱い |
| --- | --- |
| 閲覧・検索・ローカル履歴の集計 | ファイルや opencode DB を読み取り専用で参照。ローカルのキャッシュや設定は書く場合がある |
| エクスポート | ローカルの出力ファイルを作成。自動公開ではない |
| リネーム | エージェントのタイトル情報を更新。一部はタイトルレコードの追記や DB 更新 |
| ゴミ箱移動／復元 | ファイル・ディレクトリを移動、または opencode の行を変更。完全削除は保持したコピーを削除 |
| ターミナル再開／チャット続行 | CLI を起動。履歴の追記、プロバイダ通信、許可されたツールの実行が起こり得る |
| ファイル編集／ツール管理 | プロジェクト、skills、MCP、hooks、指示の設定を明示的に編集 |

「履歴の閲覧は読み取り専用」は、全機能が読み取り専用という意味ではありません。破壊的な操作の前に重要なデータをバックアップしてください。[エクスポートとゴミ箱](/ja/features/export-and-trash)も参照できます。

## 通信する場合

- **チャットと CLI 再開：**設定先のプロバイダへプロンプト、コンテキスト、添付を送る場合があります。ローカルモデルにも独自の挙動があり、内蔵チャットだからオフラインとは限りません。
- **更新確認・ダウンロード：**GitHub のリリース／更新先へアクセスします。起動時のバックグラウンド確認もあります。
- **モデル価格：**js-bridge の models.dev ミラーから価格一覧を取得し、失敗時は models.dev を使います。一覧取得のための通信で、ローカルのコスト計算に会話本文の送信は不要です。
- **契約の利用枠：**Claude／Codex の利用枠機能は認証情報や CLI のログイン状態を使って問い合わせます。ローカル履歴を読む機能とは別です。
- **MCP、hooks、シェル、外部リンク／画像：**設定したツールや参照先に依存します。それぞれの権限とプライバシーポリシーを確認してください。

外部サービスには IP アドレスなど通常のリクエスト情報が渡ります。ローカル閲覧は、アプリ・CLI・連携機能が一切通信しない保証ではありません。

## エクスポートや不具合報告を共有する前に

プロンプト、ツール出力、画像、絶対パス、添付に秘密や個人情報がないか確認してください。JSON エクスポートは解析後のメッセージデータであり、**すべてのネイティブファイルをバイト単位で保存するバックアップではありません**。完全なバックアップには元のファイルを保存してください。

不具合報告には、構造を保った最小の合成サンプルを推奨します。会話全体、DB、`auth.json`、API キー、アカウントトークン、未加工の診断ログは添付せず、再現に必要な項目だけを共有してください。
