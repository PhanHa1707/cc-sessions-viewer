# 项目文件工作区开发计划

## 目标

把项目文件编辑器从弹框改成类似工具管理的全屏工作区，并按给定 VS Code 截图补齐文件树、搜索、Markdown 预览、Git diff 和分支管理。沿用已有轻量 `CodeEditor.vue`、`GitChangesView.vue`、`GitBranchControl.vue`，不引入编辑器依赖。

## 实施步骤

1. **全屏工作区架构**
   - 从项目列表右键菜单打开 App 级项目文件工作区；关闭后恢复底下会话/分屏状态。
   - 沿用工具管理的 app chrome 和 topbar 返回/关闭行为；工作区内左侧为文件活动栏与文件树，右侧为编辑/预览/Git 内容。
   - 全屏层独立于 pane，不能因切换视图卸载底下的终端和会话。

2. **Explorer 文件树与动作**
   - 对齐 VS Code：树默认全折叠，支持逐目录展开/折叠。
   - 文件树头部提供新建文件、新建目录、刷新、全部折叠和删除操作；侧栏支持拖拽调宽，最小宽度 220px。
   - 新建文件/目录使用受项目根目录约束的后端命令；根据当前选中文件的父目录或选中文件夹定位行内输入框；点击输入框外取消。
   - 文件/文件夹支持右键删除；选中项也可用头部删除按钮；删除前二次确认，目录删除递归执行，后端拒绝越界路径和软链。
   - 未选择文件或目录时隐藏删除按钮，避免误操作。

3. **文件搜索**
   - 提供搜索视图、文本查询、大小写/全词/正则开关、包含/排除模式、文件分组及行号上下文。
   - 搜索在后端执行，遵守软链隔离、忽略依赖/构建目录、文本文件大小与结果上限。
   - 点结果打开文件并尽可能定位到匹配行。

4. **编辑、预览与 Git**
   - 普通文本继续使用现有代码高亮、行号、保存及外部变更保护；Markdown 编辑/预览按钮使用带无障碍名称的图标。
   - 图片/视频背景模式下，工作区表面保留轻度透出（透明度上限 14%）；打开工作区时隐藏下层 Pane/全局视图，避免内容重叠。
   - 所有 `.md` / `.mdx` 文件均提供可本地化的编辑/预览切换，不限于 README。
   - Source Control 视图复用 `GitChangesView` 的 working tree/commit diff；改动文件树逐级展示目录并提供拖拽分栏（220–560px）。长行 diff 保留原样，横纵滚动条使用常驻可拖动滑块。支持选择 Git 登记的主工作树或 linked worktree，查看所选工作树的未提交改动与提交 diff；不做分支基线整体对比。工作区顶栏复用 `GitBranchControl` 管理主工作树分支，菜单向右侧边缘对齐以避免裁切。
   - 项目右键入口使用“打开项目编辑器”文案和项目代码图标；支持 `⌘⇧E` / `Ctrl+Shift+E` 快捷键，并在设置列表中说明；会话顶栏批量选择图标后增加直接打开项目编辑器的入口。
   - 工作区顶栏“未提交改动”计数及 `⌘⇧B` / `Ctrl+Shift+B` 直接切换到本工作区的 Source Control 视图，不操作底层 Pane tab；内部 Git diff 状态独立于外部 Git Diff tabs。

5. **验证**
   - 增加可测后端搜索/安全边界测试。
   - 运行前端构建、前端测试、Rust 测试与 Clippy；不暂存或提交文件，除非用户明确授权。
